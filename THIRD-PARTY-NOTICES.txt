Scope
-----

These are the 73 modules linked into the released opentams and tamsctl
binaries and the published container images: every module reachable from
./cmd/... . Go links statically, so all of them are redistributed inside
those artefacts.

Modules used only to build or test OpenTAMS are not listed. They are never
redistributed, so no attribution obligation attaches to them.

Summary
-------

  MIT             34 components
  Apache-2.0      31 components
  BSD-3-Clause    11 components
  0BSD             1 component

A dual-licensed module is listed under every license it is distributed
under, so these counts add up to more than 73.

How to read this file
---------------------

Each component gives its module path, version, license, SPDX identifier and
copyright notice, followed by the license text that governs it.

Components under the Apache License 2.0 do not repeat its text. OpenTAMS is
itself licensed under Apache 2.0, so a copy travels with every artefact as the
LICENSE file, which is what section 4(a) asks for. What does vary per module
is the attribution required by section 4(d), and that is reproduced in full
with each component. An Apache-licensed module whose license file is not the
standard text is reproduced as well.

Every other component reproduces its own license file verbatim, because the
notice that has to travel with it is specific to that module: its copyright
holder, and for BSD 3-Clause the entity named in clause 3.

This file is generated from the Go module cache by `make notices`. Do not
edit it by hand. `make notices-check` fails if it is stale, and CI runs that
check on every pull request.
